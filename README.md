# 折手账（booklet-impose）

想自己印一本小册子（说明书、诗集、画册、会议手册、菜谱、绘本、毕业册）：**哪一页印在哪张纸的哪一面、
要几张纸、页数不够时白页落在哪、纸厚了内页要不要朝书脊挪几毫米、厚到要分几帖**——按对折一次的折手规则
算清，并给出可以直接照做的拼版表与打印设置。

- 体验地址：https://xululu0401.github.io/booklet-impose/
- 纯前端单文件应用：`index.html` = `template.html` + `core.js` + `ui.js`（由 `build.cjs` 拼装）
- 不联网、不上传；纸张厚度、单价与页数全部由用户填写。默认样例与内置场景都是虚构示例。

## 算法要点

1. **折手页序（对折一次，每张纸 4 页）**：一帖 N 页、m = N/4 张，第 k 张（1 = 最外）
   - 第 1 面（先印）：左 `N−2(k−1)`，右 `2k−1`
   - 第 2 面（翻面后印，左右对调后的视角）：左 `2k`，右 `N−2k+1`
   - 结构性质：每张纸 4 个面 = `{2k−1, 2k, N−2k+1, N−2k+2}`；每个半张两面是连续页对（能被装订成册的充要结构条件）。
2. **页数补齐**：骑马钉 `P′ = 4·⌈P/4⌉`，空白页位置逐格标出；胶装 / 圈装补齐到偶数、每面 1 页顺序印。
3. **分帖 DP**：`P′ > 每帖上限` 时切成若干整帖，目标「帖数最少 → 最大帖最小 → 最平坦 → 厚的在前」，与暴力枚举对拍。
4. **爬移（线性模型）**：每层厚 `L = 层厚系数 × 纸张厚度`；第 k 张内容内移 `(k−1)·L`，最内一张 `(m−1)·L`；
   不补偿时内张前口突出 `(m−1)·L`，按外张切齐的裁切量同值。
5. **装订对照**：骑马钉（4 的倍数、可平摊）/ 胶装（页数任意、不可平摊、三边裁）/ 圈装（页数任意、需打孔边距），
   书脊厚度分别按折手层厚与单张纸厚估算。

## 边界（页面内也写明）

只支持对折一次；爬移是线性模型、不是印刷机实测曲线；不做出血/裁切标记/色彩管理/双面套准；
不联网、不查打印店价格、不检查打印机；分帖不处理混合纸张与混合装订；判定性文字只是显示分组。
